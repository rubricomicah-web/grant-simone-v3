# Mogul Grant System Fix Notes

This update fixes the Funding Opportunities card overflow and improves application routing from opportunity cards.

Changes:
- Funding opportunity cards no longer overflow horizontally.
- Funding metadata stacks cleanly inside each card.
- Buttons wrap and remain inside cards.
- Open Application Page now creates an application from the selected organization profile and opens it directly.
- Added safer click handling to prevent temporary glitch/rerender behavior.
