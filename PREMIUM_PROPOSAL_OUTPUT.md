# Premium Proposal Output Update

This update changes proposal generation so client-facing documents are written from the applicant/client point of view.

## Changes
- Removed all "Prepared by Mogul Grant System" branding from generated proposal PDFs.
- PDF footer now says "Confidential Application Draft" instead of showing platform authorship.
- Proposal prompt now forbids mentioning Mogul Grant System, AI, agents, software, or system authorship.
- Business/nonprofit proposals use "we/our" voice.
- Individual proposals use "I/my" voice.
- PDF filename now uses the proposal title instead of generic Mogul Grant System naming.
- Proposal button copy is now "Create Premium Proposal Draft."

## Goal
The final proposal should feel like it came directly from the client/applicant, not from the platform.
