# All USA State Filtering

This build supports all 50 U.S. states, Washington DC, Puerto Rico, Guam, U.S. Virgin Islands, American Samoa, and Northern Mariana Islands.

Rules:
- Federal/national grants are shown for any selected state.
- State-specific grants only show when their state matches the selected state.
- No dummy/fake grants are shown. If no verified relevant grant exists, the app returns an honest no-results message.
- Grants.gov results are marked as `National`, not falsely assigned to the selected state.
